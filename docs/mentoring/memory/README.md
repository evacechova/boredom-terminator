# Projektová paměť

Sem ukládej pouze poznatky, které musí znát i další fáze nebo nový agent.

Vhodné příklady:

- nečekané chování konkrétní knihovny,
- důvod nestandardní architektonické volby,
- ověřený postup pro lokální prostředí,
- omezení hostingu nebo prohlížeče,
- TypeScript pravidlo, které ovlivňuje více souborů.

Nevhodné příklady:

- aktuální rozpracovaný krok; patří do `status.md`,
- změna proti plánu; patří do `deviations.md`,
- obecná učebnicová poznámka bez dopadu na projekt,
- detail, který je zřejmý přímo z kódu.

## Název souboru

Použij `NN-topic.md`, kde `NN` odpovídá první fázi, ve které poznatek vznikl.

## Doporučená struktura

```markdown
# Název poznatku

## Kontext

Kde a proč se problém objevil.

## Ověřený poznatek

Co jsme skutečně zjistili.

## Dopad na další práci

Co musí nový kontext zachovat nebo udělat jinak.
```
